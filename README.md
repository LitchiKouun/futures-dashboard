# 期货行情看板

在本机查看国内期货行情的看板。服务只监听 `127.0.0.1`，不提供下单、委托或账户功能。行情约每秒刷新一次，页面会标明数据来源和更新时间。

## 功能

| 页面 | 作用 |
| --- | --- |
| 工作台 | 板块概览、自选报价、主图与盘口、异动 |
| 全市场 | 报价表、热力图、涨跌幅与成交持仓排行，可按交易所和板块筛选 |
| 自选 | 添加或删除合约，查看 K 线、资讯，以及多空参考 |
| 资讯 | 按品种查看新浪财经资讯 |
| 预警 | 本机价格、涨跌幅、涨速、持仓等条件提醒 |
| 交易日历 | 交易时段与节假日；点开交易日可看当天排行 |
| 设置 | 主题、涨跌色、涨跌基准和指标说明 |
| 后台 | 查看服务状态，调整刷新间隔，暂停或立即刷新 |

合约页由全市场或自选双击进入，包含分时、K 线、买一卖一和该品种资讯。

## 环境

- Node.js 22 或更高版本
- npm 10 或更高版本

## 启动

```bash
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:5173/](http://127.0.0.1:5173/)。行情服务在 `http://127.0.0.1:8787/`，只接受本机连接。

常用命令：

```bash
npm test          # 交易日历与指标计算测试
npm run start -w server
npm run build -w web
```

自选、预警规则、主题和布局保存在本机。行情库位于 `data/`，已加入 `.gitignore`，不会进入仓库。

## 数据来源

- 全市场报价来自东方财富展示行情，默认约 1 秒拉一次快照。页面通过 WebSocket 接收变动，不经过开发服务器转发整包快照。
- K 线来自新浪财经。分钟线为原始柱，周线和月线由日线汇总。主连由真实日线拼接，换月处可能出现跳空。
- 品种资讯来自新浪财经品种频道。自选页的多空参考会再读取文章正文。
- 交易日按 `Asia/Shanghai` 计算。夜盘归入下一个交易日。节假日表写在 `apps/server/src/calendar.ts`。

价格为 0 时按缺失显示为 `--`。数据源没有昨收盘字段，涨跌默认相对昨结算；设置里切到昨收盘时，仍按昨结算计算并在页面说明。

## 指标口径

| 指标 | 计算 |
| --- | --- |
| 涨跌 | 最新价 − 昨结算 |
| 涨跌幅 | 涨跌 / 昨结算 × 100% |
| 振幅 | (最高 − 最低) / 昨结算 × 100% |
| 仓差 | 行情源给出的日增仓 |
| 委比 | (买一量 − 卖一量) / (买一量 + 卖一量) × 100% |
| 沉淀资金 | 持仓量 × 2 × 最新价 × 合约乘数 × 保证金率，持仓按单边估算 |
| 趋势度 | (最新价 − 开盘价) / (最高 − 最低) |

上涨为红色，下跌为绿色。K 线的实体、边框和影线使用同一颜色。

## 自选多空参考

选择合约后，服务读取该品种最近若干篇新浪正文，从中摘出三类依据：

- 现货价格：现货报价及其涨跌
- 库存：累库、去库和库存变化
- 消息政策：限产、停产、复产和需求变化

这些依据再与盘面涨跌、持仓变化对照。结果为 **多 1–5 星**、**空 1–5 星** 或 **中性震荡**。星级只表示材料汇总后的倾向强度，不是交易建议。

## 目录

```text
apps/server   本机行情服务，负责拉取、计算、预警和资讯正文
apps/web      React 页面
data/         运行时数据库和交易日排行，不提交
```

## 说明

本看板只汇总公开行情和规则计算。期货交易可能损失全部本金。页面信息仅供参考，不构成投资建议。
